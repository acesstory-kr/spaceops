추가한다. 동일 공간·동일 이름(비활성 포함)은 추가 대상에서 제외한다.
실패 시 일부 저장 가능성이 있어 재조회 후 남은 항목만 추가한다.

## 복구 방법
main은 변경하지 않음. 미리보기 변경을 되돌리려면 직전 보존 브랜치의
커밋으로 새 개발 브랜치를 만들어 미리보기로 검증.
운영 반영 이후라면 해당 UI 변경 커밋을 revert하는 새 커밋으로 되돌리고
검증/승인 후 운영 배포. 공유 브랜치 강제 리셋은 사용하지 않는다.
코드 복구는 DB 복구가 아니다. 이미 추가한 점검 정의는 삭제 대신 비활성화해
과거 점검 기록을 보존한다. 기존 일정/사진/계정/권한/연동 변경 없음.
