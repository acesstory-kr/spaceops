# 예약 달력 연결 삭제

기준 fb53872. 예약 연동의 URL 및 ICS 파일 달력 각각에 연결 삭제 버튼과 확인창을 추가합니다. 최고 관리자만 삭제 API를 사용할 수 있습니다. Manager/Staff는403, 비로그인은401이며 다른 Origin 요청은 차단합니다.

DELETE /api/integrations는 calendar_sources의 선택한 행만 삭제합니다. 기존 tasks/photos/sync_items/메모/완료 기록은 변경하지 않습니다. sourceCancelled 상태를 유지하기 위해 sync_items도 보존합니다. 삭제된 연결은 이후 동기화 목록에 포함되지 않으며 진행 중인 동기화 요청이 이미 시작된 경우 해당 요청은 취소하지 않습니다. 재연결은 새 달력이므로 기존 업무와 중복될 수 있습니다.

삭제 성공 후 목록에서 제거하고, 파일 달력 선택 중이었다면 선택/파일 상태를 초기화합니다. 예시 화면은 로컬 예시 연결만 제거합니다. 실제 운영 달력 삭제는 수행하지 않았습니다. DB 변경 없음. 개발 브랜치 미리보기까지만 배포합니다.
