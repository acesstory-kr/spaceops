## 구현
- 헤더 외부서비스 로고: 사용자 확인 SpaceManager /calendar, Airbnb hosting/calendar.
- iCal 연결 선택: 합정연습실·파티룸·밍글룸·혜화·상수, ICS 파일 대체.
- 외부 fetch는 기존 Airbnb 허용목록과 space.cheongsosiljang.kr만 허용, 리디렉션마다 재검증, 2MB 제한.
- 일반 공간 ICS: UID 중복 검사, UTC/Asia-Seoul 시각 지원. 알 수 없는 TZ 및 RRULE 거절.
- 파티룸 예약 전후 2h. 합정의 파티룸 제목 감지. 예약 자체도 표시.
- 밍글룸 종료 후 1h 청소. 혜화/상수 체크인 당일 15h~16h 입실 체크.
- 수동 파티룸 예약은 저장 시 전후 청소 생성(안정된 ID), 완료 청소 보존.
- 개인 캘린더와 일반 청소·세팅은 자동 청소 생성 대상 아님.
- 운영 매니저 콘솔: 담당 공간 사진/이슈 및 점검만. 인건비·사용자 관리 권한 확대 없음.
- PC 점검항목 아래 인건비 메뉴, 모바일 프로필 설정 인건비 바로가기(Owner).
- 지급 기록: 담당자, 건별/월별/중간, 대상 기간, 실제 지급일/금액/메모, 서버 기록자/시각/당시 완료 업무 스냅샷.
- 지급 기록은 자동 인건비 계산과 독립적. 자동 송금/원천세/공제/미지급잔액 추정 없음.
- 지급 기록 append-only. 잘못된 지급 기록은 삭제 대신 설명한 조정 기록이 필요(현재 UI는 양수 지급만).
- 프로필 로그인/로그아웃, 사용자 관리 단계 설명 보완. 예시 Owner/Manager 전환.

## 적용 전 확인/제한
- PAYMENT-RECORDS-PREVIEW.sql은 초안. 운영 DB 백업 및 승인 후 테이블/RLS 적용 필요.
- 실제 밍글룸/합정 예약 iCal 내보내기 주소·파일 미제공. 통합캘린더 웹주소만으로는 예약 동기화 안 됨.
- 등록한 URL 달력은 수동 동기화 방식 유지. 공급자 API/스크래핑/세션 수집 구현 안 함.
- 기존 수동 파티룸 업무는 각 업무를 저장할 때 자동 청소 생성. 일괄 변경 PATCH 후 자동 청소 연동/과거 일괄 소급은 별도 보완 필요.
- 자동 생성 작업이 동시에 수정될 경우 다음 저장·동기화 후 재확인 필요.
- 미리보기 지급/동기화는 예시만; 운영 데이터 쓰기 차단.
- 실기기 카메라/공급자 실제 ICS/운영 저장소 쓰기 검증 전.
- 기존 예정된 파티룸 업무는 설정의 '파티룸 자동 청소 생성·갱신'으로 연결 가능(Owner).
- 일괄 수정 PATCH 후에는 같은 버튼으로 자동 청소 시각을 다시 확인할 수 있다.
