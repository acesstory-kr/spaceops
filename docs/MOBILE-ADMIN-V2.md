## 사진 저장 문제
확인한 코드 결함: 기존 업로드는 파일을 multipart로 Vercel API에 보내면서 8MB까지 허용했음.
Vercel Function의 요청/응답 한도4.5MB와 맞지 않아 큰 사진은 라우트 실행 전 실패할 수 있음.
사진 조회도 서버 프록시로 같은 응답 한도에 영향을 받을 수 있었음.
또한 기존 허용 형식은 JPEG/PNG/WebP뿐이고 카메라 HEIC/HEIF는 거절됨.
이 문제가 사용자의 특정 실패를 일으켰다고 확정하지 않음. 최근30분 오류로그에 기록 없었고,
운영 사용자 계정으로 동일 파일을 재현하는 실제 저장 테스트는 아직 미실시.

수정: 브라우저에서 방향을 반영해 긴 변2000px/JPEG로 변환 → 작은 JSON으로 권한 확인 →
Supabase 단일 파일 서명URL로 직접 PUT → 서버에서 파일 크기/실제 매직바이트/업무 권한 확인 →
photos 및 photo_metadata를 한 DB 트랜잭션으로 기록 → stored=true일 때만 성공.
스토리지와 DB 사이에 분산 트랜잭션은 없으므로 DB 실패시 임시 고아 파일이 남을 수 있음.
해당 파일을 기존 사진으로 표시하지 않고 확인 영수증으로 finalize 재시도. 기존 파일 자동 삭제 없음.
읽기는 권한 검사 후60초 서명URL로 이동. 공개버킷 변경 없음. 원본 과거 사진 보존.
브라우저가 HEIC를 디코딩하지 못하면 JPG 변환 안내. 모든 HEIC 환경 지원을 주장하지 않음.
서명 업로드URL은 저장소 정책상2시간, DB 확정용 영수증은10분 유효. 경로UUID이며 덮어쓰기 금지.
재시도시 DB 확정은 중복방지. 네트워크 업로드 응답 손실시 새 파일이 생길 수 있어 고아 정리는 별도 검토.

## 모바일
- 달력은 공간/업무 두 줄, 시간은 넓은 화면에 유지, 미완료 우선 표시, +N 선택시 홈 날짜 이동.
- 하단 네 메뉴: 홈/달력/주간업무/점검항목. 프로필→설정→최고 관리자.

- 메모 인라인 편집·저장, 청소 전후 촬영/다중선택, 가로 스와이프/선택삭제/사진 확대.
