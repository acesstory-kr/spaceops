# 모바일 헤더·주간 업무 정리

기준 3ba48dd. 모바일 <=650px에만 새 헤더·주간 업무 배치를 적용합니다. PC의 기존 헤더, 주간 이동·공유·미리보기 UI는 유지합니다. 월 이동은 달력 화면에서 헤더 아래 별도 줄에 유지하며 브랜드·4개 액션은 한 줄입니다.

- 헤더: 기존 로고/SpaceOps + 개인 일정(기존 권한) / 알림 / CalendarPlus / 더보기. 새로고침·기존 서비스 바로가기·계정 설정을 더보기로 이동. 계정 로그아웃 접근 보존.
- 외부 URL은 그대로. 공유는 기존 navigator.share, 미지원 시 미리보기/복사 대체.
- 더보기: 외부 클릭·Escape 닫기, Escape 시 트리거 포커스 복귀.
- 주간 업무: 제목+공유/더보기; 가운데 이전/범위/다음, 현재 주 표시와 복귀. 개인 일정은 여전히 공유에서 제외.
- 공간색·업무카드 데이터·하단 5개 메뉴·API·DB 및 권한 변경 없음. 운영 배포 안 함.
