# 自動 정산·관리자·PC 캘린더 정리
기준: 63365b92eda26344a2e5b05fc3393f102d6ef372 (직전 운영 버전).
이전 자동 정산 기준: 30e883a. app/payroll.tsx의 기존 계산 방식 유지.
- 관리자 인건비 기본 화면에 청소 건별 자동 정산 연결.
- 기존 근무·지급 내역은 별도 버튼으로 유지. 두 금액은 합산하지 않음.
- 설정에 최고 관리자 전용 인건비 바로가기 추가. Manager/Staff 권한 확대 없음.
- 관리자 사진/정산 공간 필터. 점검은 기존 공간별 설정 유지. 사용자 관리는 공간 필터에서 제외.
- PC 헤더 아이콘/월 표시 조건 정리. 기본 날짜당 업무2개, 항목당 공간/제목2줄, 나머지 더 보기/접기.
- 모든 업무는 DB에 그대로 보존. 화면 높이는 주 수/일정 수/브라우저 크기에 따라 늘어날 수 있음.
- 정산 단가를 바꾸면 과거 조회 금액도 재계산되는 기존 동작 유지.
- API/DB/사진/계정 권한 변경 없음. 복구 시 이 커밋 revert 또는 기준 커밋 별도 검토 브랜치 사용.
